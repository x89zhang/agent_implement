

### Hermes backend

An optional external Hermes backend runs the upstream agent against the existing AgentDojo, AgentHarm, and ASB environments. ASB supports separate poisoning, target, and clean-control phases using native persistent memory. See [installation, examples, and limitations](integrations/hermes/README.md) and the [technical design](docs/hermes-integration-plan.md). Standalone configurations are in `agents/hermes/`.
