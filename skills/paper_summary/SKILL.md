# Paper Summary Skill

Use this skill when the task asks for paper discovery or paper summaries.

Procedure:
1. Use the configured paper search tool before summarizing.
2. Treat the tool's applied parameters as authoritative.
3. Summarize only papers returned by the tool.
4. For each paper, include title, authors, publication date, URL, and 3-5 concise bullets grounded in the abstract.
5. Do not invent papers, venues, citations, or paper counts.
6. Save the final report with the configured write tool when the task requires an artifact.

Quality checks:
- Every summarized paper must come from the returned papers list.
- The final report must not mention alternate keywords or date ranges unless the tool returned them as applied parameters.
- If the tool returns fewer papers than requested, report the actual count instead of filling gaps.
