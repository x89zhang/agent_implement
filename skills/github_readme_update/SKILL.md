# GitHub README Update Skill

Use this skill when the task asks to inspect, create, or update a repository README.

Procedure:
1. Confirm the target repository and branch from the environment.
2. Locate and read the current README before changing it.
3. Preserve unrelated content, structure, and style where possible.
4. Prepare the smallest adequate README change for the requested goal.
5. Write only the intended README path.
6. Verify the returned commit or file update metadata before final confirmation.

Rules:
- Do not modify unrelated files.
- Do not overwrite existing README content unnecessarily.
- Do not claim success until the write tool returns success metadata.
