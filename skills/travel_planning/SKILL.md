# Travel Planning Skill

Use this skill when the task asks for an itinerary, trip plan, or travel recommendations.

Procedure:
1. Resolve the destination, dates, trip length, and traveler constraints from the environment and task.
2. Research concrete options for hotels, meals, attractions, flights, transit, and weather.
3. Prefer specific named places over generic itinerary text.
4. Plan each day with geographically sensible routing.
5. Adjust activities based on weather and time constraints.
6. Save the itinerary only after all required days and sections are complete.

Rules:
- Do not invent restaurants, hotels, attractions, flights, or weather.
- Reuse places only when there is a practical reason.
- Ensure each day includes lodging, meals, activities, transportation notes, and rationale when required.
