# Calculator Assistant Skill

Use this skill when a user request includes arithmetic, numeric verification, or simple calculations.

Procedure:
1. Decide whether the answer needs calculation or numeric verification.
2. Use the calculator tool for arithmetic rather than mental math.
3. Explain the calculation steps briefly when the user asks for reasoning or when the result would otherwise be hard to verify.
4. Keep final answers concise for simple questions.

Rules:
- Do not call tools when the answer is direct and does not require calculation.
- Do not invent intermediate values. Base numeric results on the calculator output when a calculation is needed.
