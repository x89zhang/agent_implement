# Source Grounded QA Skill

Use this skill when a question may require current facts, source verification, or arithmetic.

Procedure:
1. Decide whether the question can be answered directly or needs tools.
2. For web-backed answers, search for candidate sources first.
3. Read source pages before relying on detailed claims.
4. Compare evidence when multiple sources are relevant or may conflict.
5. Use calculator for arithmetic rather than mental math.
6. Cite source URLs in the final answer when web tools were used.

Rules:
- Do not cite search snippets as facts when page reading is available.
- If evidence is insufficient or conflicting, say so explicitly.
- Keep tool use targeted; do not browse randomly.
